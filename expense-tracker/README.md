# Expense Tracker

Android expense-tracking app prototype built with Python/Kivy.

## Included
- PIASH header and bilingual English/Bangla interface toggle
- Add expenses with amount, category, note and date (today)
- Daily, weekly and monthly totals
- Local SQLite storage and transaction history

## Build APK
Open GitHub → Actions → "Build Expense Tracker APK" → Run workflow.
When it finishes, open the run and download the `expense-tracker-debug-apk` artifact.

This is a debug APK build. Charts and budget-setting screens are planned for the next iteration; they are not yet implemented in this prototype.
